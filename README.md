# ⚡ KotMiks Stresser v1.0

> Высокопроизводительный инструмент для комплексного стресс-тестирования веб-приложений и сетевых узлов.

---

## 🛠 Стек технологий
* **Оркестрация:** Node.js (V8 Engine)
* **Движок нагрузочного тестирования:** Grafana k6 (L7 HTTP/HTTPS Flood)
* **Сетевой уровень:** Python, Scapy (L3/L4 ICMP & UDP Flooding)
* **Интерфейс управления:** Windows Batch CLI с ANSI-стилизацией

---

## 📂 Структура проекта

```text
├── start.bat          # Интерактивное консольное меню управления
├── run.js             # Оркестратор тестов и генератор HTML-отчетов
├── load-test.js       # Сценарий нагрузки для k6 (HTTP GET)
├── net-attack.py      # Модуль сетевых атак (UDP/ICMP Flood через Scapy)
├── config.json        # Конфигурационный файл по умолчанию
├── logs/              # Директория с сырыми JSON-дампами и HTML-отчетами
└── .gitignore         # Игнорируемые файлы и директории

```

---

## 🚀 Быстрый старт

### Требования

* **Node.js** (версия 18+)
* **Grafana k6** (установленный в систему и доступный в PATH)
* **Python 3.x** с библиотекой `scapy` (при использовании сетевого модуля)

### Запуск через консольное меню

Просто запусти главный командный файл:

```cmd
start.bat

```

В открывшемся интерактивном интерфейсе выбери пункт `[01] Start Stress Test`, укажи целевой `URL` или `IP`, время выполнения и количество виртуальных пользователей (VUs).

---

## 🎨 Отчеты

После завершения каждого теста система автоматически формирует интерактивный `HTML`-отчет в папке `logs/` (или через пункт меню) со стилизованным визуальным оформлением, матричным фоном и детальным вердиктом по состоянию цели.
